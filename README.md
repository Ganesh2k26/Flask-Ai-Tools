🧠 Flask AI Tools – Sentiment, Summarization & Spam Detection
Flask AI Tools is a lightweight yet powerful web application built with Python and Flask, integrating cutting-edge Natural Language Processing (NLP) models to deliver intelligent text analysis. This multi-functional toolkit is perfect for developers, researchers, and curious minds looking to explore AI-powered language utilities.

🔍 Features
💬 AI Sentiment Analyzer Understand the emotional tone of any text—positive, negative, or neutral—using advanced sentiment classification models.

📄 AI Text Summarizer Automatically generate concise summaries from long-form content, making information easier to digest and share.

📧 Spam Mail Detector Identify and flag spam messages using machine learning techniques trained on real-world email datasets.

⚙️ Technologies Used
Python & Flask for backend logic and web routing

NLTK, TextBlob, or SpaCy for NLP tasks

Scikit-learn or TensorFlow/Keras for model training and inference
