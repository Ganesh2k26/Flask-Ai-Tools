# 🚀 Flask AI Tools

An intelligent AI-powered web application built using Flask and Python that combines multiple Natural Language Processing (NLP) utilities into a single platform. This project helps users analyze text, generate summaries, and detect spam messages using Machine Learning and AI techniques.

---

## 📖 Overview

Flask AI Tools is designed to demonstrate the practical application of Artificial Intelligence and Machine Learning in web development. The platform provides a simple and user-friendly interface for performing various text-processing tasks.

The application integrates multiple AI models and NLP techniques to help users gain insights from textual data quickly and efficiently.

---

## ✨ Features

### 😊 AI Sentiment Analyzer
Analyze the emotional tone of any text and classify it as:

- Positive
- Negative
- Neutral

Applications:
- Product Reviews Analysis
- Customer Feedback Analysis
- Social Media Monitoring

---

### 📝 AI Text Summarizer

Generate concise summaries from lengthy content while preserving key information.

Applications:
- Research Papers
- Articles
- News Content
- Documentation

---

### 📧 Spam Mail Detector

Detect whether an email or message is:

- Spam
- Not Spam

Applications:
- Email Filtering
- Fraud Detection
- Communication Security

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Ganesh2k26/Flask-AI-Tools.git
```

### Navigate to Project

```bash
cd Flask-AI-Tools
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/Mac:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

Application will run at:

```text
http://127.0.0.1:5000/
```
